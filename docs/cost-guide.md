# 비용 가이드: "이거 붙이면 한 달에 얼마 나가요?"

코딩을 몰라도 계산할 수 있게, 딱 필요한 것만 정리했다. 정확한 최신 단가는 항상 공식 콘솔(Anthropic/OpenAI)에서 확인하는 게 맞다 — 여기 있는 숫자는 "감을 잡기 위한 예시"다.

## 1. 구독 vs API, 뭐가 더 싸지?

- **구독형(`claude-subscription`/`openai-subscription`)**: 매달 정해진 요금(Claude Code Pro, ChatGPT Plus/Pro 등)으로 사용한도 안에서 무제한. **단, [README](../README.md#구독-사용-시-알아야-할-것)에 있는 "고객 행동이 LLM 호출을 직접 발생시키는가?" 규칙에 걸리면 애초에 쓸 수 없는 방식이다.** 즉 개인 프로젝트/사내 자동화가 아니라 고객이 버튼 눌러서 바로 AI를 부르는 서비스라면 이 섹션은 건너뛰고 바로 API 방식으로 가야 한다.
- **API 키(`claude-api`/`openai-api`)**: 호출할 때마다, 정확히는 **입력한 글자 수 + AI가 답한 글자 수(토큰 단위)** 만큼 과금된다. 고객이 버튼을 직접 누르는 서비스는 이 방식이 필수다.

## 2. 토큰이 뭐고, 왜 중요한가

"토큰"은 글자를 세는 단위라고 생각하면 된다. 한국어는 대략 **글자 1개 ≈ 토큰 1.5~2개** 정도로 계산된다(영어보다 토큰을 더 많이 먹는다). 예를 들어 "안녕하세요, 오늘 상담 예약하고 싶어요"(20자 안팎)는 대략 토큰 30~40개 정도다.

과금은 보통 "토큰 100만 개당 얼마" 식으로 매겨진다. 그래서:

> **한 달 예상 비용 ≈ (한 번 대화당 평균 토큰 수) × (한 달 예상 대화 횟수) ÷ 1,000,000 × (100만 토큰당 단가)**

## 3. 실제로 계산해보기 (예시)

가상의 헬스 트레이너 PT 상담봇 시나리오로 계산해보자.

- 회원 한 명이 질문 1개 보내고 AI가 답하는 것 = "대화 1회"
- 시스템 프롬프트(챗봇 성격 지시문) 포함해서 대화 1회당 평균 입력 800토큰 + 출력 400토큰 = 총 1,200토큰이라고 가정
- 회원 100명이 한 달에 평균 10번씩 질문 = 월 1,000회 대화
- 저렴한 모델(예: `claude-api`의 HAIKU급) 단가가 100만 토큰당 입력 약 1달러, 출력 약 5달러라고 가정하면:
  - 입력: 800토큰 × 1,000회 = 80만 토큰 → 약 0.8달러
  - 출력: 400토큰 × 1,000회 = 40만 토큰 → 약 2달러
  - **월 예상 비용 ≈ 2.8달러(약 4,000원) 안팎**

같은 조건에서 고성능 모델(OPUS/SOL급)로 바꾸면 단가가 10~20배 뛰기도 하니, **처음엔 저렴한 모델로 시작하고, 답변 품질이 부족할 때만 한 단계씩 올리는 걸 권장한다.**

**여기까지만 읽어도 충분하다.** "감당 가능한 수준인지" 판단이 섰다면 5번(비용 튀는 것 막는 법)으로 바로 넘어가도 된다. 아래 4번은 **유료 요금제 가격을 이미 정했거나 정하는 중인 사람만** 필요한 내용이다.

## 4. (요금제를 정하는 단계라면) "회원 몇 명까지 감당 가능한가" 역산하기

구독료를 회원에게 받는 서비스라면, 회원 1명당 원가를 먼저 계산해서 가격을 정하는 게 순서다.

```
회원 1명당 월 원가 ≈ (회원 1명이 한 달에 보내는 평균 질문 수) × (대화 1회당 토큰 수) ÷ 1,000,000 × (100만 토큰당 단가)
```

이 값이 "월 구독료의 30% 이하"가 되도록 잡는 게 일반적인 안전선이다(나머지는 결제 수수료·인프라비·이윤 몫). 정확한 숫자가 필요하면 이 문서를 코딩 AI 어시스턴트에게 보여주고 "우리 서비스 조건으로 다시 계산해줘"라고 요청하면 된다.

## 5. 비용이 갑자기 튀는 걸 막는 방법

- **모델 기본값을 저렴한 걸로 유지한다.** `createAiRunner()`는 기본적으로 각 provider의 저비용 모델을 기본값으로 쓴다 — 굳이 `model` 옵션으로 고성능 모델을 지정하지 않는 이상 비용이 커질 일은 적다.
- **`maxTokens`로 답변 길이를 제한한다.** 기본값은 1024인데, 짧은 답이면 200~300 정도로 낮춰도 충분한 경우가 많다.
- **`examples/nextjs-starter`의 rate limit·prompt 길이 제한을 반드시 유지한다.** 이게 없으면 봇/악성 사용자가 반복 호출해서 비용이 무한정 늘어날 수 있다.
- **Anthropic/OpenAI 콘솔에서 "사용량 한도(spending limit)"를 미리 걸어둔다.** 요금이 특정 금액을 넘으면 자동으로 멈추게 설정할 수 있다 — 코딩 지식 없이 콘솔 설정만으로 가능하니 서비스 오픈 전에 꼭 해두자.
