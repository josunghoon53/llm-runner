# Claude/Codex 구독으로 자동화해도 되는지, 쉽게 정리 🤖

## 기본 개념부터

Claude나 ChatGPT를 쓰는 방법은 두 가지예요.

- 🎫 **구독**: 월 $20~200 내고 "정해진 만큼" 쓰는 정기권. 원래는 "사람이 채팅창에 타이핑하는 것"을 전제로 만든 요금제예요.
- 💳 **API**: 쓴 만큼 돈 내는 요금제. 프로그램이 자동으로 부르라고 만든 거예요.

## 왜 문제가 됐냐면

구독이 훨씬 싸요. 그래서 사람들이 "프로그램에서도 그냥 구독으로 부르면 안 돼?"라고 시도했어요. 근데 회사(Anthropic, OpenAI) 입장에서는:

> "우리가 $20 받고 판 건 '한 사람이 적당히 쓸 것'을 가정한 건데, 프로그램이 24시간 계속 돌리면 우리가 손해 봐요 😥"

그래서 "구독으로 프로그램 자동화하는 거, 특히 남한테 서비스로 파는 건 안 된다"는 규칙이 생겼어요.

## 근데 여기서 헷갈리는 게 있었어요

"자동화 = 다 안 됨"이 아니에요! `claude -p`(자동 실행 기능) 자체는 회사가 **"자동화하라고 만든" 공식 기능**이에요. CI에서 코드 리뷰 자동으로 돌리는 거, 매일 새벽에 크론으로 뭔가 자동 실행하는 거 — 이런 건 원래 하라고 만든 거예요.

## 그럼 진짜 기준이 뭐냐면

딱 하나의 질문으로 정리돼요.

> **"고객이 버튼을 누르는 그 순간, AI가 호출되나요?"**

### 🙆 구독 써도 되는 경우
```
매일 새벽 3시 (내가 정한 시간)
   ↓
AI가 자동으로 뉴스 요약함
   ↓
내가(또는 담당자가) 확인하고 고침
   ↓
발행
```
→ 이건 **"내가 일하는 걸 AI가 도와준 것"**이에요. 사람이 자동으로 일하는 로봇 조수를 쓴 거랑 같아요.

### 🙅 API 써야 하는 경우
```
고객이 "삼성전자 분석해줘" 버튼 클릭
   ↓
그 순간 AI 호출됨
   ↓
고객한테 바로 답 나감
```
→ 이건 **"AI 자체가 우리 서비스의 상품"**이에요. 고객이 직접 AI를 쓰는 거니까, AI 회사한테 정식으로 이용료를 내야 해요.

## 비유로 마무리 🍽️

- **구독**: 내가 요리사를 고용해서(월급 주고) **내 레스토랑 운영을 도와달라고** 하는 것. 요리사가 새벽에 재료 손질 자동으로 해놓고, 내가 아침에 확인해서 손님상에 내는 거예요.
- **API**: 손님이 직접 그 요리사한테 주문하는 것. 이럴 땐 손님 수만큼 요리사한테 돈을 더 줘야 해요 (건별 요금).

## 한 줄 요약 📝

**AI가 "내 일"을 도와주면 구독, AI가 "고객한테 파는 물건 그 자체"면 API.** 사람이 중간에서 검수하고 판단해서 발행하는 거면 구독으로도 충분히 괜찮아요.

## 실무 체크리스트

| 패턴 | 판정 |
|---|---|
| CI/CD에서 코드 리뷰, 테스트 실패 분석 자동화 | ✅ 구독 OK |
| 매일 크론으로 브리핑 초안 생성 → 사람이 검수 → 발행 | ✅ 구독 OK |
| 사내 관리자 페이지에서만 보는 자동 요약 | ✅ 구독 OK |
| 고객이 버튼 눌러서 그 순간 AI가 호출되는 기능 (챗봇, 분석 버튼 등) | ❌ API 필요 |
| 검수 없이 AI 출력이 그대로 다수 고객에게 자동 노출되는 파이프라인 | ⚠️ 회색지대 — API 권장 |

## 알아두면 좋은 것

- 이 규칙은 2026년 한 해에만 금지 → 재허용 → 보류를 오갔어요. **정책이 계속 바뀔 수 있다**는 뜻이라, 주기적으로 공식 문서를 확인하는 게 좋아요.
- 검수 단계는 형식적으로 통과시키는 게 아니라 **진짜로 의미 있게 작동해야** "내 workflow"로 인정받을 여지가 커요.
- 판단이 애매하면, 비용 관점에서도 API가 생각보다 안 비쌀 수 있어요 (검색 상한을 걸고 저가 모델을 쓰면 구독료 수준까지 낮출 수 있음).
